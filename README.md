# JEP - Informe 2 Meses

Este repositorio contiene el proyecto para el informe de 2 meses de JEP MOBILIARI.

## Características

- Desarrollado con **React** y **Vite**.
- Proyecto de visualización de informe interactivo.

## Instalación y Ejecución

1. Instala las dependencias:
   ```bash
   npm install
   ```

2. Ejecuta el proyecto localmente:
   ```bash
   npm run dev
   ```

3. Construye el proyecto para producción:
   ```bash
   npm run build
   ```
